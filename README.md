# 월드팜 사업 검토 자료

농가의 판단과 농작업 경험을 기록해 다음 작업과 제작에 다시 쓰려는 프로젝트입니다.

월드팜 웹 개발판 v17과 Android 시험본 1.0.12(빌드 13)의 구현·배포 기록을 확인했습니다. 농가와 함께 쌓아 갈 것은 사진 속 정답뿐 아니라 **왜 그렇게 판단했고 무엇을 고쳤으며 결과가 어땠는지**입니다.

## 열람 범위

로그인 없이 읽을 수 있도록 별도로 선별한 검토 자료입니다. 원본 저장소의 공개 범위와 접근 권한은 바꾸지 않았습니다. 원본 코드·인증정보·농가 개인 기록·연락처·서명·회의 원문은 포함하지 않았습니다. 공개 자료는 복사·다운로드할 수 있으나 이 저장소 원본을 직접 수정할 권한은 부여하지 않습니다.
